## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or Docker

### Local Development

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open http://localhost:3000 in your browser

### Docker

Build and run production version:
```bash
docker-compose up food-app
```

Access at http://localhost:3000
